The clean Emerald ROM is only needed when you build a patch. pokeemerald-expansion 1.17.1 compiles without it.

Expected file, if you put one here for `tools/coop_make_patch.sh`:

- `Pokemon - Emerald Version (USA, Europe).gba`
- 16,777,216 bytes
- SHA-256 `a9dec84dfe7f62ab2220bafaef7479da0929d066ece16a6885f6226db19085af`
- SHA-1 `f3ae088181bf583e55daf962a92bb46f4f1d07b7`

Any filename ending in `.gba` is checked. A matching hash is required. The ROM, saves, and `pokeemerald.gba` are gitignored and must not be committed.
