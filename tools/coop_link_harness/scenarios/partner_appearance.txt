# Partner picture and doorways (j68 saves, post-League, linked).
# Every overworld frame the game checks the partner's picture after drawing
# it (src/coop.c Coop_CheckAppearance): one partner object at most, drawn
# only where the partner is (this map or a connected one), graphics for the
# partner's current movement mode, the partner's current outfit palette,
# the marker over that same sprite. gCoopAppearanceFaults counts failed
# frames; it must stay 0 through:
# - both players entering and leaving May's house through one door on the
#   same frames (neither blocks the other; both arrive);
# - walking straight through the partner on an open row;
# - Rosa getting on the Mach Bike, riding around Kai, getting off;
# - Rosa surfing on Petalburg's pond and landing again.
